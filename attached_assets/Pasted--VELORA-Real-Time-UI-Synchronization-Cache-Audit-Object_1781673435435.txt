# VELORA — Real-Time UI Synchronization & Cache Audit

## Objective

The application currently requires a manual browser refresh before changes appear.

Example issues:

* Add to cart → cart count does not update until refresh
* Remove from cart → item remains visible until refresh
* Add to wishlist → wishlist count updates only after refresh
* Notifications require refresh
* Settings changes require refresh
* Dashboard statistics require refresh
* Orders require refresh
* Reviews may require refresh

The database is updating correctly.

The issue is frontend cache/state synchronization.

---

## T001 — Full React Query Audit

Inspect the entire frontend.

Find every:

* useQuery
* useMutation
* queryClient usage
* invalidateQueries usage
* refetchQueries usage
* setQueryData usage

Identify mutations that do not invalidate related queries.

Fix all of them.

---

## T002 — Cart Instant Updates

When:

* add to cart

* clear cart

* cart page

* checkout page

queryClient.invalidateQueries()
